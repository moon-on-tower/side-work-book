## 本项目产生的原因
想要通过副业赚钱，是我一直以来的梦想。  
想要赚很多钱大概本来就是很多人的梦想，而我的主业暂时很难实现这一点，所以希望能够通过业余时间来拓宽经济来源。 
有些公司禁止员工告诉别人自己的工资是因为财不可外露，我们公司禁止员工告诉别人工资大概主要是因为家丑不可外扬。

出于激励自己、总结经验的目的，我决定将我学习到的方法论和真实的操作记录系统性总结出来，同时也开源分享给大家，能帮助大家多了解些信息。如果大家愿意以此为基础更多讨论、更好实践，那更是我的功德一桩了。  
当然我具体执行操作的账号和产品不会在这里公开（出于一点基础的隐私保护的目的），大家也可以看到我用的是小号。  
在具体的实现形式上，前段时间我看到范冰开源了[FDE电子书](https://github.com/xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer/>)，我非常欣赏他的形式，也很支持他所说的`知识的价值在于流动，而不在于囤积。`所以会参考他的做法。他是先开源了GitHub项目形式的电子书，后做了网站和平台，后面的那些我就以后再做吧。  
当然，他的目标是普及一项新知，所以选择了用AI协作整理出全文的做法，但我更希望是在实践中检验真理，所以我主要会用人工写作，关注在实践中更可行的方案，而覆盖面则不一定那么广泛。  
因此，可以说本项目是有私人化特征的，对于我没有实践能力和经验的领域，可能不太值得参考。而对于与我的情况又截然不同的读者们来说，可能我所介绍的内容也仅供参考了。
